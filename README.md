# Pravda Dashboard Доки

Локальный веб-тестер для API Астрал.ЭДО / 1C Docs (тестовый стенд).

## Возможности
Ответ справа и закреплённая панель «Отправить», избранное и недавние методы, поиск/скачивание/время и размер ответа, подсказка при 401 с обновлением токена и повтором, шаблоны тел запросов, сценарии (цепочки с подстановкой `{{prev.id}}`), фильтры/экспорт/импорт истории, отдельные сессии для Демо и Прод, горячие клавиши (Ctrl/Cmd+Enter, `/`, Esc), компактные формы и выбор файла, тёмная тема.

### Редактор документов
Кнопка «Редактор документов» в шапке. Готово: УПД от продавца (СЧФДОП / СЧФ / ДОП), формат ФНС 5.03, схема ON_NSCHFDOPPR_1_997_01_05_03_05; сохранение XML в windows-1251 или UTF-8. Остальные форматы ЭДО (УКД, титул покупателя) и ЭПД (ЭТрН, ЭЗН, ЭДЗ, ЭПЛ, поручение экспедитору, экспедиторская и складская расписки) помечены «Пока в работе».

## Сборка

```bash
cd Pravda_Dashboard_Docks-api
go build -o Pravda_Dashboard_Docks .
./Pravda_Dashboard_Docks
```

Windows:
```bash
GOOS=windows GOARCH=amd64 go build -o Pravda_Dashboard_Docks.exe .
```

Браузер откроется на http://localhost:8080

## Что внутри
- `main.go` — сервер: раздаёт страницу/иконки, проксирует запросы к API (`/api/proxy`, `/api/proxy-multipart`), скачивает swagger всех 17 API (`/api/specs`).
- `index.html` — интерфейс. `endpoints.js` — встроенный список методов (запасной вариант).
- `swagger.js` — разбор swagger/OpenAPI: при запуске приложение подтягивает актуальные схемы с сервера и
  дополняет методы недостающими параметрами, полями multipart (с именами и описаниями) и описанием JSON-тела.
  Состояние загрузки — плашка `swagger N/17` в шапке (клик — перезагрузить, наведение — подробности).
- `gen_syso.py` — генерирует `resource_windows_amd64.syso` (иконка exe) без внешних утилит.

Авторизация: токен применяется кнопкой **ОК** (или входом по сертификату); таймер и автообновление
(`POST /api/v2/auth/refresh`, интервал задаётся в поле «Авто-refresh») запускаются только после успешной авторизации.


## Иконка для Windows `.exe`

### Способ 1: goversioninfo (рекомендуется)

```bash
go install github.com/josephspurrier/goversioninfo/cmd/goversioninfo@latest
```

Создай `versioninfo.json`:
```json
{
  "IconPath": "icon-d.ico",
  "FixedFileInfo": {
    "FileVersion": { "Major": 1, "Minor": 0, "Patch": 0, "Build": 0 },
    "ProductVersion": { "Major": 1, "Minor": 0, "Patch": 0, "Build": 0 },
    "FileFlagsMask": "3f",
    "FileFlags": "00",
    "FileOS": "040004",
    "FileType": "01",
    "FileSubType": "00"
  },
  "StringFileInfo": {
    "ProductName": "Pravda Dashboard Docks",
    "FileDescription": "Pravda Dashboard Доки",
    "LegalCopyright": ""
  }
}
```

```bash
goversioninfo -o resource.syso
GOOS=windows GOARCH=amd64 go build -o Pravda_Dashboard_Docks.exe .
```

`resource.syso` подхватится компилятором автоматически. После сборки можно удалить `.syso`.

### Способ 2: rsrc

```bash
go install github.com/akavel/rsrc@latest
rsrc -ico icon-d.ico -o rsrc.syso
GOOS=windows GOARCH=amd64 go build -o Pravda_Dashboard_Docks.exe .
```
